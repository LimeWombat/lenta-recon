## Прочее из конфига

- `WebGLNetworkConfig` — имя класса конфига; рядом лежат пути шаблона сборки:
  `./js/server.json`, `/WebGLTemplates/TemplateBase/js/server.editor.json`,
  `Assets/Generated/NetworkManager/WebGL/Handles`.
- В сборке есть `MockBackend` (`mock_backend`) — режим игры без реального сервера (для разработки).
- Пример-фикстура с полным набором query-параметров (`token_lenta`, `customer_id`, `crm_id`, `partner`)
  зашита в сборку как тестовый образец — сам токен не приводим.
- `DataManager: requesting backend token` / `backend token received` — стартовая последовательность:
  токен из URL → `auth/token/` → дальше `player/save/`.
