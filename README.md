# ЛЕНТА 6.42.0 — разбор приложения и кастомный клиент игры «Лентомания»

Личный исследовательский проект: статический разбор Android-приложения «ЛЕНТА — каталог продуктов»
(пакет `com.icemobile.lenta.prod`, версия 6.42.0) и минимальный CLI-клиент, который умеет войти
в **собственный** аккаунт по SMS и получить ссылку на игру «Лентомания» (Unity WebGL).

## Что в репозитории

| Папка | Что внутри |
|---|---|
| `docs/` | разбор «по костям»: архитектура APK, сетевой слой, авторизация, игровой флоу, карты API |
| `client/` | CLI-клиент (Node.js, без внешних зависимостей): `login`, `me`, `coupons`, `game --open` и др. |
| `evidence/` | сырые выгрузки инструментов (REA, UnityPy) — доказательная база разбора |

Ключевые документы:

- `docs/Разбор-LENTA-APK-6.42.0.md` — основной разбор (APK + игра, §9.6 — про Unity-игру);
- `docs/api-endpoints.txt` — карта API приложения (153 эндпоинта, 33 группы);
- `docs/game-lentomania-api-map.txt` — карта API игрового бэкенда «Лентомании».

## Чего здесь нет (и почему)

В репозиторий сознательно **не** попадают чужие материалы: сам APK/APKM, декомпилированные
исходники приложения, ассеты и бинарники игры (Unity-сборка), рабочие дампы из `work/`.
Это не наши файлы — они остаются локально и не распространяются.

Также в git не попадает локальная сессия клиента (`client/.state/`): там токены твоего аккаунта.

## Как воспроизвести

1. Получить APK самостоятельно (например, с APKMirror), распаковать `.apkm` → `base.apk`.
2. Поставить инструменты: [REA](https://github.com/morluto/rea) (для Android-провайдера нужен
   `jadx-headless-mcp 0.7.1` JAR) и [JADX](https://github.com/skylot/jadx).
3. Смотреть команды и «источники правды» в `docs/Разбор-LENTA-APK-6.42.0.md` (§0 — паспорт и команды).
4. Клиент: `cd client && node lenta.mjs login` — нужен свой аккаунт и код из SMS.

## Дисклеймер

Проект — только для личного обучения и исследования. Кастомный клиент может нарушать
пользовательское соглашение «Ленты», и аккаунт может быть заблокирован. Никакого массового
использования, «фарма» наград и автоматизации лотерей здесь нет и не будет. Права на «ЛЕНТУ»
и её игровые материалы принадлежат правообладателям.
