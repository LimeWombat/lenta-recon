# ЛЕНТА 6.42.0 — разбор приложения и клиент игры «Лентомания»

Исследовательский проект из двух частей:

1. **Разбор** Android-приложения «ЛЕНТА — каталог продуктов» (v6.42.0): архитектура, сетевой слой,
   авторизация и игровой модуль — по декомпилированному коду, с указанием источников.
2. **Клиент** — небольшой CLI на Node.js: вход в свой аккаунт по SMS, профиль, купоны и запуск
   игры «Лентомания» с открытием в браузере.

> Личный исследовательский проект для самообразования. Чужие материалы — APK, декомпилированный
> код, ассеты игры — в репозиторий не выкладываются: только собственный разбор и код.

## Что умеет клиент

- `guest` — гостевая сессия (можно без аккаунта);
- `login` — вход в свой аккаунт по SMS;
- `me`, `coupons` — профиль и купоны;
- `game --open` — получает свежую ссылку на игру и открывает её в браузере;
- `raw` — произвольный запрос к API для экспериментов.

## Быстрый старт

Нужен Node.js 20+ (проверено на 24), внешних зависимостей нет:

```sh
cd client
node lenta.mjs guest          # гостевая сессия
node lenta.mjs login          # вход по SMS (придёт код)
node lenta.mjs game --open    # получить ссылку на игру и открыть её
```

Подробнее — `client/README.md`.

## Как это делалось

Статический анализ: распаковка APK-бандла, декомпиляция, разбор сетевого слоя приложения и
веб-сборки игры (Unity WebGL). Само приложение не запускалось — в документах помечено, где факт
из кода, а где предположение.

## Дисклеймер

Проект — для личного обучения и исследования. Использование кастомного клиента может нарушать
пользовательское соглашение сервиса; аккаунт может быть заблокирован. Массовое использование,
автоматический «фарм» наград и автоматизация лотерей — вне рамок этого проекта.
Права на приложение и игру принадлежат их правообладателям.
